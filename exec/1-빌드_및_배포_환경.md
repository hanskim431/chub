# 1. 빌드 및 배포 환경

## 1.1 개발 환경

### Backend
- **Java**: 21 (OpenJDK 21 / Eclipse Temurin 21)
- **Spring Boot**: 3.5.6
- **빌드 도구**: Gradle 8.12 (Wrapper 포함)
- **IDE**: IntelliJ IDEA / Eclipse (Spring Boot 지원)

- **패키지 매니저**: npm
- **React**: 19.1.1
- **TypeScript**: 5.9.3
- **빌드 도구**: Vite 7.1.7
- **IDE**: Visual Studio Code / WebStorm

- **PostgreSQL**: 16-alpine (관계형 DB)
- **MongoDB**: Atlas 클라우드 서비스 (NoSQL - 채팅)

- **웹서버**: NGINX (reverse proxy, 정적 파일 서빙)
- **WebRTC**: Coturn (TURN/STUN 서버)

## 1.3 빌드 방법

### 1.3.1 Backend 빌드

#### 로컬 빌드 (Gradle)
```bash
# Linux / Mac
cd backend/chub
./gradlew clean build

# Windows
cd backend\chub
.\gradlew.bat clean build

# 테스트 제외 빌드
./gradlew build -x test

# 애플리케이션 실행
./gradlew bootRun
```

빌드 산출물: `backend/chub/build/libs/chub-0.0.1-SNAPSHOT.jar`

#### Docker 빌드
```bash
cd backend/chub
docker build -t chub-backend:latest .
```

**Dockerfile 주요 설정:**
- **Stage 1 (Builder)**: `gradle:8.12-jdk21` 이미지로 JAR 빌드
- **Stage 2 (Runtime)**: `eclipse-temurin:21-jre-alpine` 경량 이미지로 실행
- **포트**: 8080
- **프로파일**: `-Dspring.profiles.active=prod`

### 1.3.2 Frontend 빌드

```bash
cd frontend/chub

# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 빌드 미리보기
npm run preview

# 테스트 실행
npm run test
```

빌드 산출물: `frontend/chub/dist/` (정적 파일)

## 1.5 Docker Compose 구성

**파일 위치**: `backend/docker-compose.yml`

### 서비스 구성

#### 1. PostgreSQL
```yaml
postgres:
  image: postgres:16-alpine
  container_name: chub-postgres
  environment:
    POSTGRES_DB: chub
    POSTGRES_USER: ${DB_USERNAME}
    POSTGRES_PASSWORD: ${DB_PASSWORD}
  ports:
    - "5432:5432"
  volumes:
    - postgres_data:/var/lib/postgresql/data
```

#### 2. Backend (Spring Boot)
```yaml
backend:
  build:
    context: ./chub
    dockerfile: Dockerfile
  image: chub-backend:latest
  container_name: chub-backend
  environment:
    - SPRING_PROFILES_ACTIVE=prod
    - DB_HOST=postgres
    - DB_PORT=5432
    # ... (환경변수는 2-환경변수_설정.md 참조)
  ports:
    - "8080:8080"
  volumes:
    - resume_uploads:/app/uploads/resumes
  depends_on:
    - postgres
```

## 1.6 NGINX 설정

**파일 위치**: `nginx.conf`

### 주요 설정
- **SSL/TLS**: Let's Encrypt 인증서 사용
- **클라이언트 최대 업로드 크기**: 10MB
- **정적 파일**: `/var/www/html` (React 빌드 산출물)
- **API 리버스 프록시**: `http://127.0.0.1:8080`
- **WebSocket 프록시**: `/ws/` 엔드포인트
- **파일 서빙**: `/files/resumes` → `/app/uploads/resumes`

### 주요 라우팅
```nginx
# Frontend
location / {
    root /var/www/html;
    try_files $uri $uri/ /index.html;
}

# Backend API
location /api/ {
    proxy_pass http://127.0.0.1:8080;
}

# WebSocket
location /ws/ {
    proxy_pass http://127.0.0.1:8080;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
}

# Resume 파일 서빙
location /files/resumes {
    alias /app/uploads/resumes;
}
```

## 1.7 배포 명령어

### Docker Compose 배포
```bash
cd backend

# 빌드 및 시작
docker-compose up -d --build

# 로그 확인
docker-compose logs -f backend

# 서비스 중지
docker-compose down

# 볼륨 포함 전체 삭제
docker-compose down -v
```

### NGINX 배포
```bash
# 설정 파일 테스트
nginx -t

# NGINX 재시작
systemctl reload nginx

# 또는
systemctl restart nginx
```
