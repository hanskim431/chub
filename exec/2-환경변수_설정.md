# 2. 환경변수 설정

## 2.1 Backend 환경변수

### 2.1.1 설정 파일 위치

- **개발 환경**: `backend/chub/src/main/resources/application.yml`
- **프로덕션 환경**: `backend/chub/src/main/resources/application-prod.yml`
- **시크릿 정보**: `backend/chub/src/main/resources/application-secret.yml`

### 2.1.2 필수 환경변수

#### 데이터베이스 설정 (PostgreSQL)

```bash
# PostgreSQL 연결 정보
DB_HOST=postgres              # Docker 환경: postgres, 로컬: localhost
DB_PORT=5432
DB_NAME=chub
DB_USERNAME=<your-db-username>
DB_PASSWORD=<your-db-password>

# Hibernate DDL 설정
DDL_AUTO=create               # create | update | validate | none
                              # 주의: create는 매번 테이블 재생성
```

**application-prod.yml 예시:**
```yaml
spring:
  datasource:
    url: jdbc:postgresql://${DB_HOST:postgres}:${DB_PORT:5432}/${DB_NAME:chub}
    username: ${DB_USERNAME}
    password: ${DB_PASSWORD}
    driver-class-name: org.postgresql.Driver
    hikari:
      maximum-pool-size: 10
      minimum-idle: 2
      connection-timeout: 20000
      idle-timeout: 300000
      max-lifetime: 1200000

  jpa:
    hibernate:
      ddl-auto: ${DDL_AUTO:create}
    properties:
      hibernate:
        dialect: org.hibernate.dialect.PostgreSQLDialect
        show_sql: false
        format_sql: false
```

#### 데이터베이스 설정 (MongoDB)

```bash
# MongoDB Atlas 연결 URI
MONGODB_URI=mongodb+srv://<username>:<password>@<cluster-url>/<database>?retryWrites=true&w=majority

# 예시:
# MONGODB_URI=mongodb+srv://chub_user:yourpassword@cluster0.xxxxx.mongodb.net/chub?retryWrites=true&w=majority
```

**application-prod.yml 예시:**
```yaml
spring:
  data:
    mongodb:
      uri: ${MONGODB_URI}
```

#### JWT 설정

```bash
# JWT Secret Key (Base64 인코딩된 256-bit 이상 키)
JWT_SECRET_KEY=<base64-encoded-secret-key>

# JWT 토큰 유효 시간 (분 단위)
JWT_ACCESS_TOKEN_MINUTE_TIME=60          # Access Token: 60분 (1시간)
JWT_REFRESH_TOKEN_MINUTE_TIME=10080      # Refresh Token: 10080분 (7일)
```

**JWT Secret Key 생성 방법:**
```bash
# OpenSSL 사용 (권장)
openssl rand -base64 64

# 또는 Python
python3 -c "import secrets; print(secrets.token_urlsafe(64))"
```

**application-secret.yml 예시:**
```yaml
jwt:
  secret-key: ${JWT_SECRET_KEY}
  access-token-minute-time: ${JWT_ACCESS_TOKEN_MINUTE_TIME:60}
  refresh-token-minute-time: ${JWT_REFRESH_TOKEN_MINUTE_TIME:10080}
```

#### Kakao OAuth2 설정

```bash
# Kakao REST API Key
KAKAO_CLIENT_ID=<your-kakao-rest-api-key>

# Kakao Client Secret (선택사항, Kakao Developers에서 생성)
KAKAO_CLIENT_SECRET=<your-kakao-client-secret>

# OAuth 콜백 URL (Kakao Developers에 등록된 URI와 동일해야 함)
KAKAO_REDIRECT_URL=https://chub.ai.kr/auth/kakao/callback

# Kakao Token Endpoint
KAKAO_TOKEN_URL=https://kauth.kakao.com/oauth/token
```

**application-secret.yml 예시:**
```yaml
kakao:
  oauth2:
    client-id: ${KAKAO_CLIENT_ID}
    client-secret: ${KAKAO_CLIENT_SECRET}
    redirect-url: ${KAKAO_REDIRECT_URL}
    token-url: ${KAKAO_TOKEN_URL:https://kauth.kakao.com/oauth/token}
```

#### GMS API 설정 (STT & GPT)

```bash
# GMS API Key (SSAFY 제공)
GMS_API_KEY=<your-gms-api-key>

# Whisper API URL (STT)
GMS_WHISPER_URL=https://gms.ssafy.io/gmsapi/api.openai.com/v1/audio/transcriptions

# GPT API URL (Tail Question 생성)
GMS_GPT_URL=https://gms.ssafy.io/gmsapi/api.openai.com/v1/chat/completions
```

**application-secret.yml 예시:**
```yaml
gms:
  api-key: ${GMS_API_KEY}
  whisper-url: ${GMS_WHISPER_URL}
  gpt-url: ${GMS_GPT_URL}
```

#### 파일 저장소 설정

```bash
# 파일 업로드 디렉토리 (서버 로컬 경로)
FILE_UPLOAD_DIR=/app/uploads/resumes

# 파일 접근 Base URL (NGINX를 통한 공개 URL)
FILE_BASE_URL=https://chub.ai.kr/files/resumes
```

**application.yml 예시:**
```yaml
file:
  upload-dir: ${FILE_UPLOAD_DIR:/app/uploads/resumes}
  base-url: ${FILE_BASE_URL:https://chub.ai.kr/files/resumes}
```

#### CORS 설정

```bash
# CORS 허용 출처 (쉼표로 구분)
CORS_ALLOWED_ORIGINS=https://chub.ai.kr,http://localhost:3000,http://localhost:5173

# Frontend URL
FRONTEND_URL=https://chub.ai.kr
```

**application-prod.yml 예시:**
```yaml
cors:
  allowed-origins: ${CORS_ALLOWED_ORIGINS:https://chub.ai.kr}

frontend:
  url: ${FRONTEND_URL:https://chub.ai.kr}
```

## 2.2 Frontend 환경변수

### 2.2.1 설정 파일 위치

- **개발 환경**: `frontend/chub/.env` (Git에 커밋하지 않음)
- **프로덕션**: Jenkins 빌드 시 동적 생성

### 2.2.2 필수 환경변수

#### .env 파일 예시

```bash
# Backend API URL
VITE_API_URL=http://localhost:8080           # 개발 환경
# VITE_API_URL=https://chub.ai.kr            # 프로덕션 환경

# API Mocking 설정 (개발 전용)
VITE_API_MOCK=true                           # MSW 활성화
# VITE_API_MOCK=false                        # 실제 백엔드 사용

# WebRTC STUN 서버
VITE_STUN_SERVER=stun:chub.ai.kr:3478

# WebRTC TURN 서버
VITE_TURN_SERVER=turn:chub.ai.kr:3478
VITE_TURN_USERNAME=chubuser                  # Coturn 설정과 일치
VITE_TURN_PASSWORD=chubpassword123           # Coturn 설정과 일치
```

### 2.2.3 환경변수 접근 방법

**TypeScript 코드에서 사용:**
```typescript
// vite.config.ts에서 envPrefix: "VITE_" 설정됨
const apiUrl = import.meta.env.VITE_API_URL;
const stunServer = import.meta.env.VITE_STUN_SERVER;
const turnServer = import.meta.env.VITE_TURN_SERVER;
```

**실제 사용 예시** (`frontend/chub/src/shared/api/axios.ts`):
```typescript
const baseURL = import.meta.env.VITE_API_URL || 'http://localhost:8080';

export const axiosInstance = axios.create({
  baseURL,
  withCredentials: true,
  timeout: 10000,
});
```

## 2.4 Jenkins 환경변수 (CI/CD)

### Jenkins Credentials 설정

Jenkins에서 다음 Credential ID로 등록 필요:

| Credential ID | Type | 설명 |
|--------------|------|------|
| `db-username` | Secret text | PostgreSQL 사용자명 |
| `db-password` | Secret text | PostgreSQL 비밀번호 |
| `jwt-secret-key` | Secret text | JWT Secret Key |
| `kakao-client-id` | Secret text | Kakao REST API Key |
| `kakao-client-secret` | Secret text | Kakao Client Secret |
| `kakao-redirect-url` | Secret text | Kakao Redirect URI |
| `gms-api-key` | Secret text | GMS API Key |
| `mongodb-uri` | Secret text | MongoDB 연결 URI |

### Jenkinsfile에서 사용 예시

```groovy
environment {
    DB_USERNAME = credentials('db-username')
    DB_PASSWORD = credentials('db-password')
    JWT_SECRET_KEY = credentials('jwt-secret-key')
    KAKAO_CLIENT_ID = credentials('kakao-client-id')
    KAKAO_CLIENT_SECRET = credentials('kakao-client-secret')
    KAKAO_REDIRECT_URL = credentials('kakao-redirect-url')
    GMS_API_KEY = credentials('gms-api-key')
    MONGODB_URI = credentials('mongodb-uri')
}
```

## 2.5 환경별 설정 요약

### 개발 환경 (Local)

**Backend:**
- `application.yml` + `application-secret.yml` 사용
- PostgreSQL 로컬 실행 (`localhost:5432`)
- MongoDB Atlas 클라우드 사용
- Swagger UI 활성화

**Frontend:**
- `.env` 파일에 `VITE_API_URL=http://localhost:8080`
- `VITE_API_MOCK=true` (선택사항)

### 프로덕션 환경 (Docker)

**Backend:**
- `application-prod.yml` 사용
- `SPRING_PROFILES_ACTIVE=prod` 설정
- 환경변수로 모든 시크릿 주입
- Docker Compose로 PostgreSQL과 함께 실행

**Frontend:**
- Jenkins에서 빌드 시 `.env` 동적 생성
- `VITE_API_URL=https://chub.ai.kr`
- `VITE_API_MOCK=false`
- Nginx를 통해 정적 파일 서빙

## 2.6 환경변수 검증 체크리스트

배포 전 아래 항목을 반드시 확인하세요:

- [ ] PostgreSQL 연결 정보가 올바른가?
- [ ] MongoDB URI가 유효한가?
- [ ] JWT Secret Key가 충분히 강력한가? (64자 이상)
- [ ] Kakao OAuth Redirect URI가 Kakao Developers 설정과 일치하는가?
- [ ] GMS API Key가 유효한가?
- [ ] CORS 허용 출처에 프론트엔드 URL이 포함되어 있는가?
- [ ] 파일 저장소 경로가 올바르게 설정되었는가?
- [ ] TURN/STUN 서버 인증 정보가 Coturn 설정과 일치하는가?
- [ ] DDL Auto가 프로덕션에서 `create`가 아닌가? (데이터 손실 주의)
- [ ] 모든 시크릿이 Git에 커밋되지 않았는가?

## 2.7 보안 주의사항

1. **절대 시크릿을 Git에 커밋하지 마세요**
   - `.env` 파일은 `.gitignore`에 추가
   - `application-secret.yml`은 Git에 커밋하지 않음 (템플릿만 커밋)

2. **프로덕션 환경에서는 강력한 비밀번호 사용**
   - DB 비밀번호: 최소 16자, 대소문자+숫자+특수문자
   - JWT Secret: Base64 인코딩된 64자 이상

3. **환경변수 우선순위**
   - 시스템 환경변수 > Docker 환경변수 > application.yml 기본값

4. **민감 정보 로깅 방지**
   - `application-prod.yml`에서 `show_sql: false` 설정
   - 비밀번호를 로그에 출력하지 않도록 주의
